# Changelog

## [0.1.0] - 2026-11-24

- Added build-mode setup, waiting changes, a five-section draft, and owner confirmation for a local text copy.
- Added an offline five-step meeting page with keyboard navigation, a project timeline, and a live Running Date table.
- Hid finished-work source paths from the meeting page and text copy, and formatted dates and day counts in plain English.
- Added offline Save answers and manual recording so a confirmed meeting can keep its decisions, attendees and delivery date.
- Replaced the local text copy with an A4 client PDF. Closing a week applies the recorded decisions after the PDF exists and any required paper signature is recorded.
- Closing a week now saves its promises. The next meeting shows the owner's results and keeps open decisions and needs in view.
- Added a locked record for a missed meeting, dated corrections, and dated name removal across the weekly history and client copies.
- Weekly file writes recover on the next command after an interruption.
- Added ordered screen maps with checked, dated screenshots and approved designs. The offline page and client PDF share the saved map and show when the app could not run.
- Picture and saved-answer commands can read one regular file the owner names outside the project.
- Added dated picture removal across weekly copies, with recovery and warnings for locked copies that could not be rebuilt.
- Added docs meetings before scope approval, with source-checked sentences, offline decisions, an open-question count and a matching client PDF. Docs meetings carry open questions, promises and needs forward. Entering build mode reads the approved PRD and keeps the docs history.
- Both meeting pages and PDFs can use the project's colours, local fonts and card corners. Preparation reports fallback and readability changes and saves the look with the meeting so later design edits leave its copies usable.
- Added the owner's choice of project colours or white paper for the PDF. Preparation asks when a dark design has no saved choice. Each meeting keeps its PDF colours for later copies and rebuilds.
- Added Arabic docs and build meetings, including source-checked Arabic project documents, right-to-left pages and PDFs, and Arabic notices through the weekly record. Each meeting keeps its language and fonts for later copies.
- Added a read-only date handoff for checkflow. It checks the locked dates, keeps every approved change, includes the owner's actual dates and delays, and marks the rows confirmed only with the owner's explicit confirmation.
- Preparation checks the draft for project secrets before any writes. The refusal gives the owner a setting and field to check while keeping the value private.
- Added checks for escaped saved answers, steering text, and full docs and build meetings with sockets blocked.
- Recognized more joined, plural and camel-case credential names. Authentication settings that describe flags or limits and a URL's repeated short login word can now appear in ordinary meeting text.
- Used both the setting name and value to distinguish credentials from short descriptive values. Added numbered and joined key names and passphrase names, and restored protection for credential-bearing URL, host and domain settings.
- Read trailing approval notes in English and Arabic PRD stamps and show the note with the approval date during setup or entry into build mode. Unreadable approvals stop at the PRD line so they cannot start a docs meeting by mistake.
- Added the saved decider and meeting date under each answered Change in the build meeting PDF. Existing locked PDFs keep their original bytes.
- Report malformed and misplaced English and Arabic approval stamps at their actual PRD line. Already recorded meetings can still close from their confirmed files.
- Added a guide that takes a new reader from installation to a first meeting page, plus a test that checks its commands and file names against the tool.
- Added the approved README hero showing the redesigned meeting page and client PDF, documented every CLI command and replaced real brands in test examples with fictional names.
- Added Layout C for new English and Arabic build and docs client PDFs. Build timelines mark compressed gaps and explain required signatures. Saved meetings keep the PDF layout they were prepared with.
- Added Layout A for new meeting pages and an explicit owner colour choice shared by the page and client PDF when the project has no usable design.
